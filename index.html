Tentang

Hai, Nama saya Dzul Sigma, saya mempunyai ketertarikan pada bidang Pengembangan Web dan Pemrograman. Ketertarikan saya pada teknologi dimulai sejak saya menemukan betapa menyenangkannya membangun sebuah website dan mengubah ide menjadi sebuah sistem yang dapat digunakan oleh banyak orang. Selama beberapa tahun terakhir, saya telah mempelajari berbagai teknologi dasar seperti HTML, CSS, JavaScript, dan mulai mendalami Laravel. Saya percaya bahwa kombinasi antara logika pemrograman yang baik dan tampilan yang nyaman digunakan mampu memberikan pengalaman terbaik bagi pengguna.
